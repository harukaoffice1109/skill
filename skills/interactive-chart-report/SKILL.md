# Interactive Chart Report

## 使命

将文本、Markdown、CSV/JSON/表格数据、研究材料或统计结果制作成自包含 HTML 可视化网页、数据故事和统计报告。

本 Skill 属于 Haruka Lab 的「设计视觉」流程。它应在当前环境中完成工作并留下可验证产物；如果缺少工具或权限，要明确说明可完成的部分与阻塞点。

## 何时使用

- 把标题、文章或短句做成可发布的封面、海报和信息卡。
- 生成网页封面、信息卡、PPT、海报或数据可视化报告。
- 把文字材料转成可截图、可发布、可编辑的视觉作品。

## 需要的输入

- 使用场景、画布尺寸和输出格式。
- 品牌、文案、数据、参考图与必须使用的素材。
- 视觉方向、可访问性和设备适配要求。

只询问会实质改变方案的缺失信息。能够从文件、上下文或现有页面安全确认的内容，先自行核对。

## 工作方法

1. 先建立信息层级和阅读路径，再选择能够服务内容的视觉语言。
2. 明确网格、字体、色彩、留白和组件规则，避免无目的装饰。
3. 制作可编辑源文件或实现，并为关键状态准备真实内容。
4. 渲染或截图检查构图、对齐、溢出、对比度和小尺寸可读性。
5. 根据视觉检查结果迭代，导出目标尺寸与格式。

## 交付物

- 可编辑的设计或实现文件。
- 最终渲染图、页面或演示产物。
- 尺寸、字体、色彩和使用说明。

## 边界与安全

- 不虚构来源、数据、运行结果、文件、账号状态或外部操作。
- 尊重用户指定的语言、品牌、格式、工具和修改范围。
- 涉及发送、发布、购买、删除、权限或不可逆变更时，动作前确认。

## 验收清单

- 信息层级在第一眼清楚可辨。
- 文案、数据和素材没有裁切或错误。
- 桌面、移动端或目标画布上的呈现已实际检查。
- 交付物与最初目标一致，名称、链接、命令和文件路径可用。
- 清楚标注未验证项、限制和最有价值的下一步。
