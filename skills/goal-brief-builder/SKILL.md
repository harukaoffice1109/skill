# Goal Brief Builder

## 使命

把模糊或复杂的 Agent 任务整理成目标、范围、约束、证据和完成标准清晰的执行简报。

本 Skill 属于 Haruka Lab 的「Agent 工作流」流程。它应在当前环境中完成工作并留下可验证产物；如果缺少工具或权限，要明确说明可完成的部分与阻塞点。

## 何时使用

- 把复杂任务拆成可执行工作流，并沉淀为可复用 Skill。
- 设计、测试、发布和维护 Agent Skill。
- 需要多模型、多代理或严格验收的高风险任务。

## 需要的输入

- 目标、受众和最终交付物。
- 现有材料、工具权限和不能越过的边界。
- 成功标准、时间限制与需要保留的证据。

只询问会实质改变方案的缺失信息。能够从文件、上下文或现有页面安全确认的内容，先自行核对。

## 工作方法

1. 把请求改写为结果、范围、约束和验收标准，不把任务拆解误当成最终产物。
2. 识别能够并行的研究、执行和审查工作，并明确每一步的责任与依赖。
3. 先建立最小可行路径，再完成主体交付物并记录关键决策。
4. 让独立审查覆盖事实、逻辑、完整性和可执行性，修正后再交付。

## 交付物

- 可直接执行的任务说明或工作流。
- 完成的主体产物，而不只是建议。
- 验证结果、限制和下一步。

## 边界与安全

- 不虚构来源、数据、运行结果、文件、账号状态或外部操作。
- 尊重用户指定的语言、品牌、格式、工具和修改范围。
- 涉及发送、发布、购买、删除、权限或不可逆变更时，动作前确认。

## 验收清单

- 所有子任务都能追溯到用户目标。
- 结论与证据、假设与事实清楚分开。
- 交付物可以被下一位协作者直接继续使用。
- 交付物与最初目标一致，名称、链接、命令和文件路径可用。
- 清楚标注未验证项、限制和最有价值的下一步。
