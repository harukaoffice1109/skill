# Ebook Source Locator

## 使命

在合法可访问的公开目录、图书馆或用户提供来源中定位电子书，并核对版本与文件信息。

本 Skill 属于 Haruka Lab 的「阅读研究」流程。它应在当前环境中完成工作并留下可验证产物；如果缺少工具或权限，要明确说明可完成的部分与阻塞点。

## 何时使用

- 把网页、链接或资料抓取成干净 Markdown 再进入后续处理。
- 抓取网页、论文、电子书、Newsletter 或知识库资料。
- 把多源内容转成 Markdown、NotebookLM、PPT 或长文素材。

## 需要的输入

- 研究问题、用途和期望深度。
- 来源范围、时间范围、语言与引用格式。
- 已有材料以及不能访问或不能使用的来源。

只询问会实质改变方案的缺失信息。能够从文件、上下文或现有页面安全确认的内容，先自行核对。

## 工作方法

1. 把问题拆成可验证子问题，先定义证据标准和检索边界。
2. 优先获取原始、权威或最接近事实的来源，并记录出处。
3. 提取与问题直接相关的论点、数据、方法和限制。
4. 交叉核对冲突信息，区分来源陈述、分析推断和未知项。
5. 围绕决策或理解目标综合结论，给出可追溯引用。

## 交付物

- 结构化摘要或研究报告。
- 来源清单与关键证据。
- 分歧、限制、未知项和后续研究建议。

## 边界与安全

- 不虚构来源、数据、运行结果、文件、账号状态或外部操作。
- 尊重用户指定的语言、品牌、格式、工具和修改范围。
- 涉及发送、发布、购买、删除、权限或不可逆变更时，动作前确认。

## 验收清单

- 每个关键结论都有相邻证据支持。
- 没有用二手摘要替代可获得的原始来源。
- 引用能够回到具体页面、章节或文件。
- 交付物与最初目标一致，名称、链接、命令和文件路径可用。
- 清楚标注未验证项、限制和最有价值的下一步。
